# Core dependencies -- everything the default setup needs (Chatterbox-Turbo +
# Kokoro voices, faster-whisper STT, any OpenAI-compatible LLM).
#
# End users: don't install these by hand, just run VCB.bat -- it sets up a
# private Python, the right PyTorch build for your GPU, and everything below.
#
# Manual install (developers):
#   1. PyTorch first, matching your hardware:
#        NVIDIA GPU: pip install torch==2.7.1 torchaudio==2.7.1 --index-url https://download.pytorch.org/whl/cu128
#        CPU only:   pip install torch==2.7.1 torchaudio==2.7.1 --index-url https://download.pytorch.org/whl/cpu
#   2. uv pip install -r requirements.txt -c requirements-lock.txt --override requirements-overrides.txt
#      (chatterbox-tts pins an older torch/newer transformers than we use; the
#      overrides file resolves that. Plain pip has no overrides: use
#      `pip install --no-deps chatterbox-tts` after the rest instead.)
#   Optional TTS engines (xtts / orpheus / csm): requirements-extras.txt
